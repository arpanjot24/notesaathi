# NoteSaathi

Android app that turns photos or PDFs of notes (any language) into clean English study notes in a
handwriting font: pointers, coloured key terms, a summary and a story mnemonic for each page, with
a ruled margin on the right of every page for your own notes.

**Install:** on your Android phone, open the [latest release](../../releases/latest) and download
`NoteSaathi.apk`. The app checks this page for new versions and offers to update itself.

Three ways to read a page, chosen in Settings:

- **On this phone, no key** – free, on-device, for printed or very neat English and Hindi.
- **Google Gemini** – needs your own API key; reads handwriting in any language.
- **Anthropic Claude** – needs your own API key.

Keys are stored only on the phone. The Kalam font is by Indian Type Foundry (SIL Open Font License).
